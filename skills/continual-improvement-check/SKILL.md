# Continual improvement check

For an AI or agent workflow that will handle repeated real tasks, ask:

> Could representative real outcomes from this system become evaluated improvements to later versions?

Record a one-sentence answer in the plan. If yes, name one outcome signal worth keeping and one quality check that could judge it. Stop there unless the user asks to design the improvement loop.

Done when the plan contains a direct answer.

Inspired by Shopify Engineering's Sidekick continual-learning loop: https://shopify.engineering/sidekicks-continual-learning-loop
