# Resolve connection and capability notes

Use this reference only after a brief and cut plan exist. Check the installed Resolve developer scripting documentation and the MCP tool list on the actual workstation. Version and edition determine whether any command below exists; these sources are research leads, not an installation order.

- [Blackmagic developer updates](https://www.blackmagicdesign.com/developer/) announce Studio 21.1 AI-assistant integration and new scripting APIs, but the public listing does not specify the integration's tool names. Prefer inspecting the bundled integration on the installed Studio version before selecting a third-party server.
- [Blackmagic Studio features](https://www.blackmagicdesign.com/products/davinciresolve/studio) list external Python/Lua scripting as a Studio feature. On the free edition, do not assume external scripting works. Some older free builds admitted in-app Python menu scripts, but [this server's compatibility notes](https://github.com/samuelgursky/davinci-resolve-mcp#free-edition-in-app-bridge) report a free 21.1 build where the Python menu entry disappeared.
- [samuelgursky/davinci-resolve-mcp](https://github.com/samuelgursky/davinci-resolve-mcp) documents a grouped local-stdio server using Resolve's scripting API and an optional advanced offline server. Inspect its [security policy](https://github.com/samuelgursky/davinci-resolve-mcp/blob/main/SECURITY.md), [installation guide](https://github.com/samuelgursky/davinci-resolve-mcp/blob/main/docs/install.md) and [version-dependent API limitations](https://github.com/samuelgursky/davinci-resolve-mcp/blob/main/docs/reference/api-limitations.md) before trial. Prefer grouped, local-only actions. Leave its offline project/database editing server disabled unless separately reviewed and approved.
- For a free edition without safe live edit controls, [unofficial-davinci-mcp](https://github.com/wassermanproductions/unofficial-davinci-mcp) documents FCPXML/EDL output for manual import. A [Lua bridge](https://github.com/saadk408/davinci-resolve-lua-mcp) reports free 21.1 use, but its reel assembly depends on unrestricted `run_lua`; do not give that to an unattended editor.

For Codex, discover currently supported MCP configuration from its own documentation/CLI and inspect existing user settings before proposing changes. Explain any permissions, third-party installer side effects, network listeners, auto-updates, costs, or file writes; obtain approval before changing them. Use a disposable project and test clip for a live smoke test before client footage. Verify a recovery/rollback route and compare timeline plus rendered output. If a capability is absent, state the exact gap rather than silently switching to a riskier transport or arbitrary code.

Source review checked 2026-09-24. Recheck sources on activation; Resolve and third-party integrations change independently.
