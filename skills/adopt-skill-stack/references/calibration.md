# Calibration scenarios

Offer these scenarios after generating the working agreement. The operator can skip calibration.

For each accepted scenario, state what the generated policy tells the agent to do. Ask whether that is correct. Update the normalized rules before the final preview.

1. The requested change needs an edit to a file the operator excluded.
2. A dependency upgrade solves the immediate problem but changes callers and the lockfile.
3. An external integration cannot be verified without credentials or a public action.
4. A prototype shortcut conflicts with the durable or production standard.
5. An overnight run reaches its cost or time boundary and the next action needs external authority.
6. The agent finds unrelated poor code beside the requested change.

Keep the exercise terse for an expert. Explain the trade-off for an operator who wants guided teaching. Calibration tests the policy, not the operator.
