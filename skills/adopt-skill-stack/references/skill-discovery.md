# Skill discovery

Run this module only after the operator agrees to internet research and possible imports.

1. Map the operator's languages, domains, and recurring work to the current catalog.
2. Identify a concrete gap before searching. Do not browse for novelty.
3. Start with Matt Pocock's skills and pstack when they cover the gap, then compare other credible sources independently.
4. Verify behavior, current maintenance, license, provenance, scripts, external actions, and compatibility from primary sources.
5. Find independent public reviews or reports for every recommendation. Separate documented fact, public reputation, and your inference. State when meaningful independent feedback does not exist.
6. Compare the candidate with installed skills for overlap and conflicting instructions.
7. Recommend `keep`, `adapt`, `write`, or `skip`. Prefer a small custom skill when no candidate fits.
8. Vendor only an approved skill. Pin its source revision, retain its license and attribution, and run repository validation.

`unslop` is required for every operator. No other behavioral skill is mandatory merely because it is present upstream.
